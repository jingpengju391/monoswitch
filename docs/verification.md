## 硬件验收步骤

1. 用显示器菜单验证两台电脑分别有视频输出，开启 DDC/CI。
2. 两台电脑分别完成本地组件安装，确认扩展识别系统和当前输入。
3. 各自按接线选本机接口，交换配对码，检查对端输入不同于本机输入。
4. 从当前显示的电脑切到另一台，再从另一台切回，分别检查画面和显示器实体菜单。
5. 验证拔线、休眠、输入源读取失败时出现合理提示，不自动重复发送切换命令。

「指令已发送」不是画面已切换的确认。扩展不通过 HDMI/DP 推断远端系统，也不自动共享键盘鼠标。

- 中英文界面：验证浏览器语言默认选择、手动切换、持久化、跨页面同步，且电脑名称保持原样；检查英文设置页与安装引导截图。
